# Public Repository Safety Policy

This repository is intentionally public-safe.

Allowed: generic role contracts, schemas, deterministic policies, synthetic companies/work items, public references and non-secret evaluation fixtures.

Forbidden: real customer/employee data, credentials/tokens, private email addresses, account identifiers, tax/financial records, contracts under confidentiality, private KPIs, internal company configuration, production endpoints, private system identifiers, real incident payloads or proprietary prompts copied from a private company.

Private implementations reference sensitive evidence by opaque IDs inside private repositories/systems. Raw sensitive content never belongs here.

A green scanner is not proof that content is safe to publish. Human review remains required for novel data types or examples.
